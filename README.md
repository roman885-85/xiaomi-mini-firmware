# Прошивки точки доступу Xiaomi Mini

Канал оновлень для точки доступу Wi-Fi церкви «Відродження».

* `update.json` — опис найсвіжішої версії: номер збірки, адреса файлу, розмір і контрольна сума.
* Самі файли прошивок лежать у розділі **Releases**.

Пристрій щоночі зазирає сюди, звіряє номер збірки й контрольну суму і, якщо дозволено,
ставить оновлення сам. У панелі це сторінка **Керування → Оновлення**, там же є вимикач.

Вихідний код прошивки — у закритому сховищі `roman885-85/xiaomi-mini-keenetic`.
